# WP-04 评审记录：Game resolver、cache 与视觉管线

> 本文是实现评审材料，不是新的实现契约。用户已接受 WP-04 并授权 WP-05；WP-06 至 WP-10 继续保持 `blocked`。

## 范围结论

本包实现了完整 versioned Game ID、注入 catalog port、staging publish、不可变 digest cache、canonical manifest/tree digest、offline hit/miss、Raw Frame validation、1024×1024 Visual、ACTION6 坐标映射、region/read-pixel 纯逻辑和确定性 PNG publisher。

本包没有实现 official catalog 网络 adapter，没有下载或执行真实 Game，也没有加载 fixture 中的 Python。Python sidecar、Environment 生命周期、controller、Pi runtime、CLI 和 SDK 均未开始。

## Game cache 契约

required tests 使用 committed minimal fixture，发布后的稳定 tree 为：

```text
<game-cache>/
└── ls20-9607627b/
    └── e570152a34ae99af6f71dc6ec1661e35435ea8f447ba0144624bdecc0cd57261/
        ├── manifest.json
        └── environment/
            ├── environment.py
            └── metadata.json
```

- cache miss 先写入 `.staging-<uuid>/environment/`；catalog identity、文件类型、symlink、必需文件和 digest 全部通过后才 rename 发布。
- cache hit 每次重新读取 canonical `pi-arc.game-cache.v1` manifest，并逐文件核对 path、size、SHA-256 和 tree digest。
- cache root、Game directory、content root、environment root 和 tree 内任意 symlink 都会拒绝；path traversal、未列文件、内容漂移、多个 published digest 和非 digest entry 同样 fail closed。
- `game-offline` miss 在调用 catalog 前拒绝；resolver 没有旧项目搜索路径，行为测试即使在邻近位置放置 `memo-arc` 副本仍返回 `game_cache_miss`。
- 相同 digest 的并发 publisher 已完成发布时，当前 resolver 验证并复用既有目录，不覆盖内容。

## Raw Frame 与 Visual

- Raw Frame 必须是 `1..64 × 1..64` 的非空矩形整数网格，颜色固定为 `0..15`；ArtifactStore 与纯视觉逻辑复用同一 validator。
- ARC palette 固定为 arc-agi 0.9.9 的 16 个 RGB 值；Raw Frame 以无平滑最近邻规则生成固定 1024×1024 Visual。
- ACTION6 使用 `floor(coordinate × 64 / 1024)`；固定向量 `0/15/16/1023 → 0/0/1/63`。
- region 必须完全位于 Visual 内；inspect primitive 精确裁剪后按最长边 1024 等比例最近邻放大。
- pixel primitive 按等分 bin 中心采样，单次最多 4096 个 sample，不执行颜色解释或图像推断。
- PNG 固定 RGB 8-bit、filter 0、无 metadata 和固定压缩参数；2×2 golden Visual 的 PNG SHA-256 为 `78bccd99ac2e6f9c4029fe92d4f7cdefec57ffbff84f067197ae6fe45868577f`。测试同时校验 PNG signature、IHDR 1024×1024 和 IDAT 解压结果。
- Visual publisher 使用稳定路径 `visuals/tNNNNNN/fNNNNNN.png`、`.partial → rename` 和 write-once 幂等语义；partial marker 可由既有独立 audit 检出。

## Schema 与 fixture

- `schemas/source.json` 新增 `pi-arc.game-cache.v1`，生成 schema 总数从 13 增至 14。
- Raw Frame schema 已收紧到宽高与 row count `1..64`、颜色 `0..15`。
- TypeScript/Python schema validator 同步支持 `maxItems`；共享 corpus 覆盖合法 Game cache、path traversal、palette overflow 和 65-row Frame。
- Game fixture 只有小型 metadata 和一个无行为的测试常量，不包含旧项目文件或真实数据集内容。

## 已知边界

1. official `arc-agi` catalog adapter 与人工真实下载 smoke 尚未实现；本包只固定并测试注入 port 和可信发布边界。
2. 下载的 Python code 只能由 WP-05 sidecar 在受控 offline 环境加载；TypeScript resolver 永远不执行它。
3. inspect/read_pixels 的模型工具 envelope、跨视图 palette symbol 和 64-view 总量编排属于 WP-07；本包只实现确定性视觉 primitive。
4. controller 把 Raw Frame、PNG、Visual reference 和 Turn commit 组成同一事务证据属于 WP-06；本包提供可组合的 write-once publisher。
