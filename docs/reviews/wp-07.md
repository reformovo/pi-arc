# WP-07 评审记录：模型工具与知识边界

> 本文是实现评审材料，不是新的实现契约。WP-07 已通过用户审核；未接入 Pi runtime、真实模型或 CLI/SDK。

## 范围与边界

- `ModelToolExecutor` 实现 provider-neutral 的九个工具：`play`、`inspect`、`read_pixels`、`history`、GUIDE/WORKING 读写和 `save_compact_checkpoint`。
- `ArtifactEvidenceReader` 只从已提交 Turn、Environment receipt、Raw Frame、Visual index 和确定性 PNG 归档读取；Turn commit 保存响应的 `frameCount`，防止索引末帧缺失时默默退回较早帧。模型 transcript、临时文件和 Environment live state 不进入只读工具。
- `KnowledgeStore` 负责 versioned Markdown、`knowledge.commit` marker、GUIDE/WORKING projection、RESET retry_state activation、Level archive、checkpoint request/commit 和可重放 boundary envelope。
- VISTA Codex 完整系统提示独立存于 `src/application/prompts/prompt.md`，pi-arc 的两句补充要求存于 `pi-arc-addendum.md`；composition loader 读取文件，application 仅做纯文本组合。`model-prompts.ts` 另固定九个工具的 description/schema hint、checkpoint 注入、初始任务与边界恢复消息。六个工具描述逐字复用；`play`、`history`、`write_working` 仅按已接受的 pi-arc 契约最小改动。来源、哈希和差异见 `docs/design/vista-prompt-baseline.md`。
- schema source 增加 `checkpoint.request`；生成 schema、artifact adapter 和 run controller 已同步，但本包没有把工具接到 controller 的生产 composition。
- 所有新增源码文件头和语义注释使用中文；坐标、Action6 映射和 image content 规则沿用已接受规范的 1024×1024 契约。

## 知识与边界证明

- GUIDE/WORKING snapshot 先以 `.partial` + rename 发布，再追加 `knowledge.commit`；没有 commit marker 的快照不会进入 projection。
- RESET 的 `retry_state` 只在包含 `boundaryPending` 的 `turn.commit` 后成为新 Attempt 的活动 WORKING；Action intent、拒绝或 Unknown Outcome 不会覆盖原 WORKING。
- Level 切换时，projection 先清除活动 WORKING；旧版本写入 `knowledge/level-archive/`，重复归档按字节幂等。
- checkpoint 使用稳定 invocation、checkpoint request、anchor 和内容摘要；一次 commit 中的 GUIDE/WORKING 双快照使用全局最大 knowledge version + 1 分配，避免后续版本冲突。
- Context Boundary 以 `reset-{sequence}` 或 `checkpoint-{sequence}` 作为稳定 boundary ID；先持久化可重放 envelope，runtime 确认模型可见后才追加 `acknowledged` marker。准备后、确认前的崩溃仍保持 Action gate；重复取得 envelope 不会再次 RESET 或再建快照。
- 视觉读取验证 Turn commit 的 Frame 数量、Raw Frame identity、receipt frame（若存在）、content digest、唯一 Visual index 引用和确定性 PNG 字节；缺失或篡改归档分别分类为 `not_found`/`storage_failure`。

## 故障矩阵与验收结果

| 故障 | 预期语义 | 验证 |
| --- | --- | --- |
| 工具输入非法或未知 schema | 结构化 `invalid_request`，无 Environment/知识副作用 | 通过，覆盖所有九个工具及 malformed envelope |
| checkpoint 未 request | `invalid_request`，不写 commit | 通过 |
| checkpoint snapshot 写入中断 | 无 commit marker，request 仍 active；同 anchor 可重试 | 通过 fault-injected I/O |
| checkpoint commit 后 boundary delivery 中断 | 可重复取得相同 envelope；确认前 gate 不解除，不改变 Game/Turn | 通过 |
| RESET commit 前读取 WORKING | 保留旧 WORKING | 通过 |
| RESET commit 后重复 boundary | 同 envelope；仅一条准备记录和一条幂等确认记录 | 通过 |
| Level 切换 | 清除活动 WORKING，归档旧 Level | 通过 |
| Raw Frame、receipt、Visual index 或 PNG 损坏 | 只读工具拒绝；不得用近似 Visual 继续 | 通过 |
| terminal Run | history/notes/视觉读取可审计；play/写操作结构化 `terminal` 拒绝 | 通过 |
